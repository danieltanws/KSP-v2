# outputs

Products that do not belong in `docs/` or `ksp/`.

| Folder | Holds |
|---|---|
| `docs/` | Documentation about this system, for whoever maintains it |
| `ksp/` | The stores — LAB, LEAD, and LION if it is ever built |
| **`outputs/`** | Everything else this agent produces |

Files land here **when asked for**, not automatically. Answering a question
does not write a file.
